**0.2.55 release candidate — pending integration of PR #2.**

Planned changes from PR #2 (not included in this dry-run build):

- **Three levels in To-do.** Organise work as tab titles, tasks and subtasks. A parent is complete only when all its children are complete.
- **To-do data and interactions.** The new hierarchy keeps parent and child state consistent across the To-do page, shelf and app state.
- **Release scope.** The planned release includes the To-do work from the Antigravity branch `ag/todo`. The release branch is based on `origin/main`; the feature PR must be merged before the tag is created.

**Install:** download `Halo-Island-Setup.exe` and run it. It installs just for you (no admin rights) and can start with Windows. Or unzip the portable zip and run `Halo\halo.exe`.

**Upgrading:** run the new Setup over the old one. It upgrades in place and keeps your settings, data, add-ons, sign-in and license.

The Windows build isn't code-signed yet, so Windows SmartScreen may say "Windows protected your PC". Click **More info → Run anyway**.
