## What's new in 0.3.0

- **Liquid Glass Dock**: Bottom dock matches Halo Island's GPU glass and theme look with specular highlights and recessed tray well.
- **Launchpad & Squircle Tiles**: Dedicated 9-dot Launchpad slot, squircle tiles, notification badges, and browser download progress rings.
- **Fan-Out Downloads & Minimized Thumbnails**: Cascaded Downloads fan-out stack and live minimized window thumbnail cards.
- **Rich Control Capsule**: Passive weather pill, Wi-Fi/volume/battery status cluster, date+time stack, and `Force Liquid Glass dock` toggle in Settings.

## Release engineering

The v0.3.0 binary adds the dock, Launchpad, thumbnail, control-capsule, and
related Windows integration covered above. The existing release size budgets
were v0.2.x baselines, not platform limits; measured v0.3.0 outputs are
10.65 MB (`halo.exe`) and 3.45 MB (installer). The size-only budgets are
rebaselined to 11.00 MB and 3.60 MB. CPU, memory, wake-up, and thread budgets
remain unchanged.
