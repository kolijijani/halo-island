Trust & Frequently Asked

Straight answers before you install.

Why does Windows SmartScreen appear?

Halo Island is an independent open-source Windows app. On first launch, click More info → Run anyway. Every release is built transparently in GitHub Actions.

Does it slow down games or battery?

No. Idle animations pause automatically when the screen locks, display turns off, or Battery Saver is active. At rest it uses 0% CPU and ~28–36 MB RAM.

Installer vs Portable?

Halo-Island-Setup.exe installs cleanly in your user folder with no admin rights. Prefer zero installer? Extract and run portable Halo\halo.exe.

What about macOS?

macOS is Coming soon. v0.3.0 focuses 100% on Windows 10 & 11 first so the Liquid Glass Dock and Genie physics feel native on Windows.
