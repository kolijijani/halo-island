**A new cat icon, and Halo Island now updates itself.** The app wears the mascot's new face, and every copy from this one on finds new versions on its own, downloads them and asks before it installs.

- **A new icon.** Halo, the grey British Shorthair, with round ears and capsule eyes, drawn from the approved design B. It is the same at every size Windows asks for: the eyes sit on whole pixels, and at 16 and 20 px the head fills the square so it still reads as the cat. The installer's pictures carry it too.
- **Updates, on their own.** Halo Island reads its signed update file a couple of minutes after it starts and then every hour, and **Check for updates…** in the menu or **Check now** in Settings reads it at once. When a later version is out on GitHub, it downloads that version's Setup once, keeps it only if its size and SHA-256 match the signed file, and then says **Update available** on the island. The Update sheet reads **Update ready to install**, with **Install now** (closes, updates and opens again) or **Install on next start** (before it next opens). Nothing installs until you pick one. After the install, the island says **Updated to** the new version. The reads wait while the PC is locked, the display is off or battery saver is on.

**What it costs:** one read of a file of about 1 KB an hour, and the Setup (about 3 MB) once per release. The icon file grows from 18 KB to 36 KB.

**Install:** download `Halo-Island-Setup.exe` and run it. It installs just for you (no admin rights) and can start with Windows. Or unzip the portable zip and run `Halo\halo.exe`.

**On a Mac:** open `Halo-Island-Mac.dmg`, drag Halo Island into Applications and open it.

**Upgrading:** 0.2.40 can't look for updates yet, so install this one by hand: run the new Setup over it. It upgrades in place and keeps your settings, data, add-ons and sign-in. From 0.2.41 on, the island tells you.

The Windows build isn't code-signed yet, so Windows SmartScreen may say "Windows protected your PC". Click **More info → Run anyway**.
