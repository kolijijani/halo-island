**The license server is built in, so a Pro code redeems against it out of the box.** This build carries the license server's address and signing key, where the last build said "no license server" when you entered a code. Enter a Halo Pro code and it now reaches the server, one seat at a time.

- **Redeeming a code now works.** The app ships with the license server's redeem address and its signing key baked in, instead of waiting for a deployment setting. Entering a Pro code asks the server, and the daily check reads the server's answer, so a moved or revoked seat drops promptly. The server is only asked while a server license is on.
- **The admin portal keeps its Diorama look.** The license portal's design is restored, with the "View key" button that shows a license key right after it is created (older keys stay hashed, so they can't be shown).

**What it costs:** nothing new runs at rest. A code redemption reads one small answer once; the daily check reads once a day, only while a server license is on, and skips while the PC is locked, the display is off or battery saver is on.

**Install:** download `Halo-Island-Setup.exe` and run it. It installs just for you (no admin rights) and can start with Windows. Or unzip the portable zip and run `Halo\halo.exe`.

**Upgrading:** run the new Setup over the old one. It upgrades in place and keeps your settings, data, add-ons, sign-in and license.

The Windows build isn't code-signed yet, so Windows SmartScreen may say "Windows protected your PC". Click **More info → Run anyway**.
